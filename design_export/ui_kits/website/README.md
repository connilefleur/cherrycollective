# Cherry Collective — Website UI kit

A high-fidelity recreation of the Cherry Collective marketing site, derived from the live screenshots and the brand copy in `content/home-page-text.md`.

## Files
- `index.html` — composition. Loads tokens + components and renders a working multi-section landing page.
- `Header.jsx` — sticky header band with wordmark, nav, primary CTA, and mobile menu.
- `Hero.jsx` — full-bleed photo hero with serif display, oxblood overlay, three CTAs.
- `WasIstCherry.jsx` — long-form "what is Cherry" section with stat cards.
- `Workshop.jsx` — workshop schedule (3 evenings + coaching).
- `IstCherryFurDich.jsx` — "Is Cherry for you?" arrow-bullet checklist.
- `Founders.jsx` — founder portrait + signed-essay block.
- `Waitlist.jsx` — waitlist form with cohort counter.
- `Community.jsx` — membership tiers (Young Cherry / Cherry / Patron / Boost).
- `Footer.jsx` — cream footer with red links.

## Surfaces covered
- Hero
- Section headers (eyebrow + serif display)
- Pill buttons (primary, outline, ghost)
- Form fields (pill inputs)
- Stat cards
- Founder portraits
- Long-form arrow-bullet lists
- Pricing tiers

## Caveats
This is a **cosmetic recreation** built from screenshot + copy. The repo at `connilefleur/cherrycollective` is currently empty, so component implementations are not pulled from production code.
